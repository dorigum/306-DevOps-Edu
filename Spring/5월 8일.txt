1. 생성과 관련된 Annotation은?
     @Component - 일반클래스 생성
          --> 상속
                   @Controller - 사용자요청 처리하는 영역
                   @Service - B/L담당
                   @Repository - DAO=영속성과 관련된(DB연동)

     * 위 4개의 어노테이션은 spring spec에서 제공하는 생성 

    @Bean -> 생성 
       => 사용자 정의 클래스가 아니라 spring에서 제공하는 클래스를 생성하고 싶을때 사용하는 어노테이션
       => 메소드 선언부 위에 작성
      <bean class="org.springframework.beans.factory.config.PropertyPlaceholderConfigurer">
     <property name="locations">
      <array>
         <value>classpath:info.properties</value>
         <value>classpath:db.properties</value>
      </array>
     </property>
   </bean>

      @Bean  //xml의 위에 태그와 동일
     public PropertyPlaceholderConfigurer getPropertyPlaceholderConfigurer(){
           PropertyPlaceholderConfigurer p =new PropertyPlaceholderConfigurer();
           p.setLocations(리스소배열);

          return p;
     } 


    @Configuration -> 환경설정을 돕는 클래스 위에 선언 (생성)


     @Configuration -> 환경설정을 돕는 클래스 위에 선언 (생성)
     public class AppConfig{
          @Bean  //xml의 위에 태그와 동일
         public PropertyPlaceholderConfigurer getPropertyPlaceholderConfigurer(){
           PropertyPlaceholderConfigurer p =new PropertyPlaceholderConfigurer();
           p.setLocations(리스소배열);

          return p;
       } 
     }

2. 주입과 관련된 Annotation은?
    @Autowired
        => 같은 타입을 찾아서 주입(byType)
        => 만약 같은 타입을 여러개 찾으면 byName -> 클래스의 id와 property=field 명이 일치하는 객체를 찾아서 주입
        => required=true로 설정되어 있어서 반드시 주입이 되어야만 실행이된다.
        => 클래스의 id와 property=field이 일치하지 않을때 그 이름을 직접 매핑 시킬수 있도록 @Qualifier를 사용 할수 있다.

     lombok제공하는 @RequiredArgsConstructor + final필드를 이용한 주입

4. @PostConstruct 는 무엇인가?
     => spring제공하는 lib아니고 javax.annotaion에서 제공한다.
     => 객체가 생성되고 주입된후에 해야 할 일이 있다면 메소드 선언위에 @PostConstruct 를 선언하면
          메소드가 주입된후에 호출된다
    <dependency>
	 <groupId>javax.annotation</groupId>
	<artifactId>javax.annotation-api</artifactId>
	 <version>1.3.2</version>
  </dependency>

5. lombok LIB란?
   => 반복되어지는 코드(보일러플레이트코드)를 자동으로 생성해주는 라이브러리
