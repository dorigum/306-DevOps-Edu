### 작업 목적

퍼블리싱 완료된 정적 웹사이트(HTML/CSS/jQuery)를 React(Vite) 기반의 현대적인 웹 애플리케이션으로 변환합니다.  
기존의 jQuery 인터랙션은 React State로 대체하고, 모든 스타일은 `styled-components`를 사용하여 컴포넌트 단위로 재구성합니다.

## 파일별 기능 명세

### 1. `index.html`

Vite 전용 엔트리 HTML로 교체합니다.

| 항목 | 내용 |
|------|------|
| 역할 | React 앱 마운트 진입점 |
| 마운트 포인트 | `<div id="root"></div>` |
| 외부 폰트 | Raleway (400, 600, 800), Noto Sans KR (300, 400, 500, 700) |
| 스크립트 | `<script type="module" src="/src/main.jsx">` |

**변경 전 (정적 HTML):**  
jQuery, Swiper CDN 스크립트를 직접 `<script>` 태그로 로드, 전체 HTML 마크업 포함

**변경 후 (Vite):**  
폰트 링크만 포함, React 앱이 `#root`에 마운트

### 3. `src/App.jsx`

라우팅 및 전역 Provider를 설정하는 루트 컴포넌트입니다.

| 역할 | 내용 |
|------|------|


## jQuery → React 변환 대조표

| 기능 | 기존 jQuery 코드 | 변환된 React 코드 |
|------|-----------------|------------------|
| GNB hover depth2 | `.mouseover()` + `.slideDown()` | `useState(hoveredIndex)` + `onMouseEnter` |
| GNB leave depth2 | `.mouseleave()` + `.slideUp()` | `onMouseLeave(() => setHoveredIndex(null))` |
| 전체메뉴 토글 | `.hasClass("on")` + `.show()/.hide()` | `useState(allMenuOpen)` + toggle 함수 |
| 조건부 클래스 | `.addClass("on")` / `.removeClass("on")` | `className={open ? 'on' : ''}` |
| Swiper 초기화 | `new Swiper('.swiper1', {...})` | `<Swiper modules={[...]} ...>` |
