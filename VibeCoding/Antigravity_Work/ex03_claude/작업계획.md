# 리액트 프로젝트 변환 작업 계획서

## 1. 개요
현재 퍼블리싱 완료된 정적 웹사이트(HTML/CSS/JS)를 React(Vite) 기반의 현대적인 웹 애플리케이션으로 변환합니다. 모든 스타일은 `styled-components`를 사용하여 컴포넌트 기반으로 재구성하며, 기존 jQuery 기반의 인터랙션을 React의 상태 관리(State Management)로 대체합니다.

## 2. 기술 스택
- **Framework**: React (Vite)
- **Language**: JavaScript
- **Router**: react-router-dom v7
- **Styling**: styled-components
- **Slider**: Swiper (React 버전)
- **Icons/Images**: 기존 이미지 자원 활용 (`public/img`)

## 3. 프로젝트 구조 (Proposed Structure)
```text
src/
├── assets/             # 정적 자원 (필요 시)
├── components/         # 공통 컴포넌트
│   ├── common/
│   │   ├── Header.jsx  # 헤더 (GNB 포함)
│   │   ├── Footer.jsx  # 푸터
│   │   └── Layout.jsx  # 레이아웃 구성
│   └── main/           # 메인 페이지용 컴포넌트 (Visual, Product, Section 등)
├── pages/              # 페이지 컴포넌트
│   └── Home.jsx        # 메인 페이지 (/)
├── styles/             # 전역 스타일 및 테마
│   ├── GlobalStyle.js  # 전역 스타일 (reset.css, common.css 통합)
│   └── theme.js        # 공통 컬러 및 변수
├── App.jsx             # 라우팅 설정
└── main.jsx            # 엔트리 포인트
```

## 4. 상세 작업 단계

### 1단계: 프로젝트 초기화
- Vite를 사용하여 React 프로젝트 생성 (`npm create vite@latest . -- --template react`)
- 필수 패키지 설치: `styled-components`, `react-router-dom`, `swiper`
- 기존 `img/` 디렉토리를 `public/` 폴더로 이동하여 경로 유지

### 2단계: 스타일 시스템 구축
- `src/styles/GlobalStyle.js` 생성: 기존 `reset.css`, `common.css` 내용을 `createGlobalStyle`로 이관
- `src/styles/theme.js` 생성: 자주 사용되는 색상, 폰트 사이즈 등 정의

### 3단계: 공통 컴포넌트 분리
- **Header**:
  - `gnb` 마우스 오버 시 `depth2` 출력 인터랙션 구현 (State 사용)
  - `allmenu` 클릭 시 전체 메뉴(`allgnb`) 토글 기능 구현
- **Footer**: 하단 회사 정보 및 카피라이트 영역 컴포넌트화

### 4단계: 메인 페이지(Home) 구현
- `src/pages/Home.jsx`에 `index.html`의 `#main` 영역 이관
- **Swiper 적용**: 기존 `swiper1`, `swiper2`를 `swiper/react` 컴포넌트로 대체
- 각 섹션(Visual, Product, Construction Case, BBS)을 필요에 따라 별도 컴포넌트로 분리하여 가독성 확보

### 5단계: 라우팅 및 연동
- `App.jsx`에서 `react-router-dom`을 사용하여 `/` 경로에 `Home` 페이지 연결
- `Layout` 컴포넌트로 페이지를 감싸 Header/Footer가 공통 적용되도록 설정

## 5. 확인 사항
- **jQuery 제거**: 기존 `js/script.js`의 jQuery 코드를 모두 React 로직으로 변환합니다.
- **이미지 경로**: `img/` 폴더의 자원들을 리액트 환경에 맞게 참조하도록 수정합니다. (절대 경로 `/img/...` 사용 권장)
- **반응형**: 기존 CSS에 포함된 미디어 쿼리를 `styled-components` 내부에 그대로 이식합니다.
