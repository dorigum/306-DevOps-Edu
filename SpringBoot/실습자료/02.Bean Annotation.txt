  <bean.... --- 대신   --> @Bean   생성

      @Bean를 선언할수있는 클래스가 필요하고 그 클래스가 환경설정을 돕도록
          @Configuration

           @Bean을 하고 싶은 클래스가 있을때 메소드를 만들어서 사용한다.

     ex)

        @Configuration  //환경설정 기반의 어노테이션을 돕는 선언
        public class UploadConfig{

              @Bean  //생성
              public CommonsMultipartResolver   test(){
                    CommonsMultipartResolver cm =new CommonsMultipartResolver();
                     cm.setXxx()
                   return cm;
             }
        }
