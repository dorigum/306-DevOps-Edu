임차인의 돈을 지키기 위해 집의 안전 점수를 산출하는 과정은 이 서비스의 **가장 핵심적인 백엔드 로직이자 알고리즘 어필 포인트**입니다.

부동산 전문가들이 권리분석을 할 때 쓰는 공식을 프로그래밍 로직으로 변환하여, **AI(서류 해독)와 백엔드 시스템(수치 계산)이 협업하여 점수를 도출하는 3단계 평가 시스템**을 스케치해 드릴게요.

## 🛡️ 안전 점수 산출을 위한 3대 핵심 지표

점수는 100점 만점을 기준으로 하며, 아래의 3가지 영역에서 감점하는 방식으로 산출합니다.

```
[최종 안전 점수 (100점)] = ① 권리 분석 (50점) - ② 매물 건전성 (30점) - ③ 임대인 신용 (20점)
```

### ① 권리 분석 영역 (50점) - "내 보증금을 돌려받을 수 있는가?"

등기부등본의 '을구(근저당권)'와 공공데이터의 '주택 가격'을 비교하여 계산합니다. 부동산 학계와 허그(HUG)에서 깡통전세를 판정하는 가장 확실한 기준입니다.

- **핵심 공식 (부채 비율):**
    $$\text{부채 비율} = \frac{\text{선순위 채권(은행 대출)} + \text{내 전세 보증금}}{\text{해당 주택의 실제 매매가(공공 시세 데이터)}} \times 100$$
    
- **점수 산출 알고리즘:**
    - **부채 비율 60% 이하:** 매우 안전 (**0점 감점**)
        
    - **부채 비율 70% ~ 80%:** 경고 (**15점 감점**)
        
    - **부채 비율 90% 이상:** 깡통전세 위험, 경매 넘어가면 보증금 날림 (**50점 전액 감점 ➔ 즉시 '위험' 등급**)
        

### ② 매물 건전성 영역 (30점) - "서류상 하자가 없는가?"

등기부등본의 '갑구'와 '건축물대장'에서 위험 키워드를 AI가 OCR로 찾아내어 감점합니다.

- **위험 키워드 매칭 감점 필터:**
    - **위반건축물 표시 (건축물대장):** 빌라인데 베란다를 불법 확장했거나 근린생활시설(상가)을 주거용으로 속인 경우 (**30점 전액 감점**)
        
    - **압류 / 가압류 / 가처분 (등기부 갑구):** 집주인이 돈을 못 갚아 집이 국가나 채권자에게 묶이기 직전인 상태 (**30점 전액 감점**)
        
    - **신탁 (등기부 갑구):** 소유권이 신탁회사로 넘어가 있어서, 신성한 신탁회사의 동의 없이 집주인과 계약하면 불법 점유자가 됨 (**20점 감점**)
        

### ③ 임대인 신용 영역 (20점) - "집주인이 나쁜 사람은 아닌가?"

앞서 차별화 포인트로 짚었던 HUG 악성 임대인 명단 및 세금 체납 여부를 대조합니다.

- **감점 기준:**
    - **HUG 블랙리스트 명단 일치:** 보증금 상습 먹튀범 (**20점 전액 감점**)
        
    - **국세/지방세 상습 체납자:** 집이 세금 안 내서 경매(공매)로 넘어갈 확률 높음 (**10점 감점**)
        

## 💻 백엔드 로직 연동 시나리오 (Data Flow)

이 과정을 백엔드 코드로 구현할 때는 **정형 데이터 계산**과 **비정형 AI 분석**을 분리하여 처리합니다.

**1.1단계: OCR 텍스트 추출 및 마스킹:**FastAPI / Spring Boot.

유저가 올린 등기부등본을 OCR로 읽어 텍스트화한 뒤, 개인정보(주민번호 뒷자리 등)를 마스킹합니다.

**2.2단계: AI 변수 추출 (JSON 구조화):**OpenAI API.

AI에게 "을구의 근저당권설정 총액수, 갑구의 압류/신탁 여부를 찾아서 JSON으로 줘"라고 요청하여 `근저당금액: 1억 2천`, `신탁여부: true` 같은 정형 데이터를 뽑아냅니다.

**3.3단계: 오픈 API 시세 조회 및 연산:**국토부 실거래가 API.

백엔드가 해당 주소의 국토부 매매 시세(예: 2억)를 가져와서, AI가 뽑아준 대출금액과 유저가 입력한 보증금을 공식에 넣어 **부채 비율을 수학적으로 계산**합니다.

**4.4단계: 최종 점수 매핑 및 리포트 출력:**DB 저장 및 프론트 전송.

감점 로직을 모두 거친 최종 점수(예: 85점)를 계산하고, 유저 화면에 **Green(안전, 80점 이상), Yellow(주의, 60~79점), Red(위험, 60점 미만)** 신호등 UI로 시각화합니다.
