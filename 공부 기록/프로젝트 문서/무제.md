## 현실적인 제약 3가지 (미리 알아둘 것)

1. **도메인 등록이 필수** — Kakao Developers 콘솔에서 _앱 → 플랫폼 → Web_에 실제 서비스 도메인을 등록해야 SDK가 로드돼요. **이 미리보기 환경은 도메인 등록이 안 돼서 실 API는 회색 화면**이 떠요. 그래서 디자인 단계에선 목업을 쓴 거고요. (배포하실 도메인·localhost는 등록하면 정상 작동)
    
2. **'도보 N분'은 SDK가 안 줘요** — JS 지도 SDK엔 도보 소요시간 기능이 없어요. 거리는 좌표로 계산되지만, 도보 시간은 직선거리÷도보속도로 추정하거나 별도 길찾기 API를 붙여야 해요. 지금 카드에 쓰는 "도보 6분"은 그래서 추정값 표기 정책을 정하는 게 좋아요.
    
3. **POI 검색의 카테고리 한계** — 대중교통·병원·약국·마트는 카카오 로컬 검색의 카테고리 코드(`SW8 지하철, HP8 병원, PM9 약국, MT1 대형마트, CS2 편의점`)로 깔끔하게 받아와요. 그런데 **'동물병원'은 전용 카테고리 코드가 없어서** 키워드 검색(`동물병원`)으로 처리해야 합니다. 방금 분리한 반려동물 카테고리가 여기 해당돼요.
