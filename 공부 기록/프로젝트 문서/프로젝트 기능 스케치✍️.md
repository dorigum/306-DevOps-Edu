# 🏠 임차인 맞춤형 안심 주거 가이드, ZIPT (집PT)

> **연결 키워드:** 프라이스 디코딩(Price Decoding) | 제로클릭(Zero-Click) | 휴먼 인 더 루프(Human-in-the-Loop)
> 
> **한 줄 요약:** 정보 비대칭성으로 고통받는 임차인을 위해, AI 서류 해독과 공공데이터를 결합하여 계약 전후 리스크를 올인원으로 케어하는 풀스택 서비스


---
## 🎯 1. 핵심 서비스 기능 (Function)
### ① AI 부동산 서류 디코더 & 용어 요약 (프라이스 디코딩)

- **기능:** 유저가 등기사항전부증명서(등기부등본)나 건축물대장(PDF/이미지)을 업로드하면 AI가 복잡한 권리 관계를 해독합니다.
    
- **해독 가이드:** 
	- **갑구:** 소유권 변동, 압류, 가압류, 가처분, 신탁 등 위험 키워드 분석
    - **을구:** 근저당권 및 융자 상태를 분석하여 주택 시세 대비 부채 비율 계산
        
- **용어 번역기:** 딱닥한 법률 용어를 사회초년생의 언어로 풀어서 요약합니다. (예: 근저당권설정 ➔ 집을 담보로 은행에서 빌린 돈)
    
- **HUG 시뮬레이션:** 백엔드 연산 결과 부채 비율이 90%를 넘을 경우, 전세보증보험 가입 불가 사유를 안내하고 위험(Danger) 경고를 제공합니다.
    
### ② 하이브리드 맞춤형 체크리스트 (휴먼 인 더 루프)

- **기능:** 서류 분석 결과(전/월세 구조)와 집의 형태(아파트/원룸)를 기반으로, 현장에서 꼭 확인해야 할 체크리스트를 동적으로 생성합니다.
    
- **구현:** 국토교통부·서울시 가이드라인 기반의 기초 데이터 위에 유저가 직접 현장 상태(수압, 곰팡이, 계약서 특약 등)를 체크하여 최종 '계약 진행 안전 보고서'를 도출합니다.
    
### ③ 디데이(D-Day) 리마인드 퀘스트 타임라인

- **기능:** 계약 날짜를 기준으로 임차인이 법적 보호를 받기 위해 놓치면 안 되는 필수 일정을 게임의 퀘스트 형태로 알림을 제공합니다.
    
- **가이드:** 본계약 당일(등기부등본 발행일시 확인 퀘스트), 이사 당일(전입신고 및 확정일자 신청 퀘스트) 등 일정 리마인드 및 행동 지침 전달.

## 🗺️ 2. 데이터 기반 주거 환경 분석 (Infrastructure & Environment)

### ① 공공데이터 기반 지역별 소음 통계

- **기능:** 계약 전 개별 호수 단위로 알기 어려운 층간소음 리스크를 우회적인 통계 데이터로 제공합니다.
    
- **구현:** 공공데이터포털 또는 자치구 데이터를 활용하여 매물 주소지(시/군/구)의 연도별 층간소음 민원 발생 빈도를 대시보드 차트로 시각화합니다.
    
### ② 초개인화 인프라 브리핑

- **기능:** 매물 좌표 기준 반경 500m~1km 이내의 생활 인프라 정보를 수집하고, 유저의 라이프스타일 성향 키워드(예: `#뚜벅이`, `#요리초보`)에 맞춰 AI가 맞춤형 텍스트 분석을 제공합니다.
    
- **수집 인프라 범위:**
    - **대중교통:** 지하철역 및 버스 정류장까지의 도보 시간/거리
    - **편의시설:** 편의점(편세권), 대형마트, 코인세탁소 위치
    - **의료서비스:** 응급실 운영 병원 및 연중무휴/야간 약국 필터링 정보

## 🔩 3. 기술 관점 및 시스템 아키텍처 (Technical View)

### ① 핵심 기술 스택

- **Main API 서버:** FastAPI (Python) 또는 Spring Boot (Java)
- **OCR 엔진:** Upstage Document OCR API 또는 Naver CLOVA OCR 연동
- **데이터베이스:** PostgreSQL (유저 및 매물 데이터), Redis (캐싱 및 알림 처리)
- **AI 엔진:** OpenAI API (GPT-4o) 활용
    
### ② 개발자 구현 및 최적화 팁

- **지오코딩(Geocoding):** 유저가 입력한 주소 텍스트를 카카오 로컬 API를 통해 위도/경도 좌표로 변환 후 DB에 저장합니다.
    
- **API 호출 최적화 (Redis 캐싱):** 동네별로 변하지 않는 정적 인프라 정보는 Redis에 캐싱하여 외부 API 호출 비용을 절감하고 응답 속도를 개선합니다.
    
- **프론트엔드 Map 시각화:** 카카오맵/네이버맵 API 연동을 통해 매물 위치 및 주변 인프라 마커를 카테고리별 필터로 제어할 수 있는 인터랙티브 UI를 구현합니다.
    
### ③ ZIPT 핵심 AI 에이전트 프롬프트 (System Prompt) 구조

- **역할 정의:** 2030 임차인 편에 서서 가감 없이 권리 관계를 독자적으로 해독하는 부동산 분석가.
    
- **출력 데이터 규칙:** 할루시네이션 방지를 위해 정형 수치 연산은 백엔드에서 처리하고, AI는 문서를 해석하여 **구조화된 JSON 형식**으로만 백엔드에 반환하도록 강제합니다.

## 🌟 4. 기존 서비스와의 차별점 (USP)

1. **임차인 전용 가드 플랫폼:** 중개사와 임대인의 매물 홍보 중심인 기존 대기업 플랫폼(직방, 다방 등)과 달리, 철저히 정보 약자인 '임차인 보호'만을 목적으로 불리한 정보까지 가감 없이 투명하게 제공합니다.
    
2. **제로클릭 올인원 케어:** 서류 열람, 리스크 질문, 지도 검색, 체크리스트 작성 등 파편화되어 있던 임차인의 탐색 여정을 '주소 입력 및 서류 업로드 딱 한 번'으로 압축하여 제공합니다.
    
3. **실행(Action) 중심의 UX:** 단순한 정보 조회를 넘어, AI 기반 임차인 맞춤형 특약사항 문구 복사 기능 제공, D-Day 임무 가이드 등 실질적인 행동을 유도하고 밀착 케어하는 페이스메이커 역할을 수행합니다.
