# Scope란?
- Scope는 **데이터(정보)가 살아있는 범위와 유지 시간**을 의미한다.
- Servlet/JSP에서는 데이터를 저장하고 여러 페이지에서 공유하기 위해 Scope 객체를 사용한다.

```text
pageContext < request < session < application
```

- 즉, 오른쪽으로 갈수록 **데이터 유지 범위와 생명주기**가 커진다.

![[20260526_092935.jpg]]

## Servlet에서 **==Scope==** 제공 
1. HttpServletRequest -> request
2. Http Session -> session
3. Servlet Context -> application
