# React Redux
> React 애플리케이션에서 상태 관리를 효율적으로 하기 위한 라이브러리로 Redux의 전역 상태 저 장소를 React 컴포넌트에서 쉽게 사용할 수 있게 도와준다.
> 상태를 중앙에서 관리함으로써 예측 가능한 상태 흐름과 디버깅이 가능해진다.


## 용어 정리

### 1. Redux(https://redux.js.org/)
> Redux는 **자바스크립트** 앱에서 상태를 예측 가능하게 관리하기 위한 **상태 관리 라이브러리**
> React뿐만 아니라 Vanilla JS, Angular, Vue 등 어떤 UI 라이브러리/프레임워크와도 사용 가능

**핵심 개념**
- **Store**: 상태를 저장하는 중앙 저장소
- **Action**:  상태 변경 요청 객체(type, payload)
	- type: 수행되는 특정 작업을 식별하는 필수 문자열 -> **'무슨 일이 일어났는지'**
	- payload: 상태 업데이트를 수행하는 데 필요한 추가 데이터가 포함 -> **'어떤 데이터로 일어났는지'**
- **Reducer**: 상태를 변경하는 순수 함수
- **Dispatch**: action을 스토어에 전달하는 함수

### 2. React-Redux(https://react-redux.js.org/)
> Redux를 React에서 쉽게 연동할 수 있도록 도와주는 공식 바인딩 라이브러리
> React 컴포넌트와 Redux store를 연결해 주는 역할

**주요 기능**
- `<Provider store = {store}>` : 전역 상태를 리액트 컴포넌트에 주입
- **`useSelector()`** : store의 상태를 읽을 수 있게 함(조회)
- **`useDispatch()`** : action을 dispatch할 수 있게 함(발송)

### 3. Redux Toolkit (RTK - https://redux-toolkit.js.org/)
>Redux의 복잡한 설정과 보일러 플레이트 코드를 줄이기 위해, Redux 팀이 공식적으로 만든 권장 도구 모음

- Redux의 설정을 단순화
- 자동으로 action 생성자, reducer 생성, 불변성 유지 등 제공
- **`configureStore()`, `createSlice()`, `createAsyncThunk()`** 등의 API 제공

📝**정리하면**,
**==세 가지는 각각의 역할이 다르지만, 함께 사용되며 상호보완적으로 협력하는 관계이다.==**

**비유 예시**
- Redux = 요리법의 원칙과 구조
- React-Redux = 주방과 식탁을 연결하는 서빙 도구(식탁 = React 컴포넌트)
- Redux Toolkit = 주방 도구 세트 (요리를 쉽게 만드는 도구들)
