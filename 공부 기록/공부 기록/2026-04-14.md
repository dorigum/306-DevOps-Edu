## Docker란?
- 2013년 3월에 나온 컨테이너 기반의 오픈소스 가상화 플랫폼이다.
- **Docker**는 애플리케이션을 실행하는 데 필요한 모든 것(코드, 라이브러리, 설정 파일 등)을 하나의 **컨테이너(container)** 라는 독립된 단위로 묶어, **어디서나 동일한 환경**에서 실행할 수 있도록 해주는 **가상화 기술이다.(빠른 배포, 이식성(Portability), 경량화된 가상 환경(VM보다 훨씬 가벼움))**

### 도커의 장점 / 단점
**장점**
- 1대의 물리적인 서버(Host PC)에 여러 대의 서버를 구동할 수 있다.
- 다른 소프트웨어에 영향을 미치지 않으면서 컨테이너 교체나 수정이 쉬워, 서버 관리가 용이하다.
- 명령어 한 줄로 서버 구축이 가능하기에, 서버 고수가 아니어도 다루기가 수월하다.

**단점**
- 리눅스 소프트웨어만 지원한다.
- 호스트 서버에 문제가 발생할 시, 모든 컨테이너에 영향을 미친다.
- 컨테이너를 하나만 사용하는 경우에는 비효율적이다.


### 도커의 주요 활용
**팀원들에게 동일한 개발 환경 제공**
- 함께 일하는 프로젝트 팀원들에게 개발 환경을 동일하게 제공

**새로운 버전의 테스트**
- 새로운 운영체제나 라이브러리 버전을 개발 환경에서 먼저 테스트 후, 운영 환경에 컨테이너를 적용

**동일한 서버가 여러 대 필요한 경우**
- 1대의 물리 서버에 여러 개의 컨테이너를 이용할 수 있으므로 비용 절약
- 명령어 한 줄로 원하는 만큼 서버 구동 가능 -> **배포 시간 단축**
- **스케일링**에 유리하므로 웹 서버나 API 서버로 많이 활용

**도커는 리눅스 운영체제가 필요하며,** 도커는 리눅스 기반을 전제로 만들어졌다.
