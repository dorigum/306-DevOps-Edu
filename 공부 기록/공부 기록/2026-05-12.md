#### was쪽에서 이동하는 방식
  1\) redirect방식 - 새로운 request와 response 생성해서 이동방식
  
  ```java
  response.sendRedirect\(url주소\);
  ```

  2\) forward방식 - 기존 request, response 유지 하면서 이동방식

```java
request.getRequestDispatcher\(url주소\).forward\(request, response\);
```

### Httpstatus code
- 500
- 404
- 400
- 405 [`405 Method Not Allowed`](https://developer.mozilla.org/ko/docs/Web/HTTP/Reference/Status/405)
	- 요청한 메소드는 서버에서 알고 있지만, 제거되었고 사용할 수 없습니다. 예를 들어, 어떤 API에서 리소스를 삭제하는 것을 금지할 수 있습니다. 필수적인 메소드인 `GET`과 `HEAD`는 제거될 수 없으며 이 에러 코드를 리턴할 수 없습니다.


`@ModelAttribute`
1. 메소드 선언부 위에 작성
	- 현재 컨트롤러를 실행했다가 뷰로 이동하는 모든 요청이 공유해서 사용한 정보(data) 설정(공유 정보)
	
2. 매개변수 옆에 작성
	- 뷰 쪽으로 전달되는 객체의 정보에 별칭을 설정할 때 사용

### 예외 처리
1. 각 Controller마다 예외 처리(Class 단위)
	- 메소드를 작성하고, 메소드 위에 `@ExceptionHandler` 선언
	
2. 하나의 프로젝트에 Global(전역) 예외 처리
	- 클래스를 만들고, 클래스 선언부 위에 `@ControllerAdvice` 선언
	- 각 메소드를 작성해서 `@ExceptionHandler` 선언

- RestXxx -> 비동기 통신
